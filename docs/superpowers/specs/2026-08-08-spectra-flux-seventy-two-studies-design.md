# SPECTRA FLUX 七十二种动态设计

## 目标

在保留现有 01–36 动态及其编号、名称和着色器表现的前提下，新增三组、每组十二种高级动态，将网站扩展为六页共七十二种效果。每页仍只渲染十二张卡片，并继续共享一个 WebGL atlas，因此页面运行负载不随总目录数量翻倍。

## 六组目录

1. `01–12｜雾与薄纱`
2. `13–24｜光学材质`
3. `25–36｜流体力场`
4. `37–48｜晶体生长`
5. `49–60｜电磁脉冲`
6. `61–72｜天体引力`

## 37–48｜晶体生长

- 37 晶核萌生：多个晶核从点状快速长出
- 38 冰枝蔓延：树枝状结晶向四周扩张
- 39 矿脉贯穿：彩色矿脉在材质中穿插
- 40 棱面折叠：透明多面体缓慢翻折
- 41 晶簇碰撞：两组晶体撞击、挤压并交错
- 42 裂隙发光：发光裂纹连续分叉扩散
- 43 结晶潮汐：液态颜色逐层凝固成晶面
- 44 宝石呼吸：内部折射随呼吸节奏明暗起伏
- 45 晶格错位：规则晶格发生剪切和位移
- 46 盐花扩散：细密结晶边缘向外持续生长
- 47 棱镜破片：彩色碎片喷散后重新聚合
- 48 晶体坍缩：大型晶簇向中心塌缩并再结晶

## 49–60｜电磁脉冲

- 49 磁极对撞：相反磁极高速靠近并形成亮缝
- 50 电弧跃迁：分叉电弧在多个节点之间跳跃
- 51 场线缠绕：成束磁力线相互编织和翻转
- 52 脉冲爆发：能量核心周期性释放冲击波
- 53 等离子喷流：高亮等离子束横向高速喷射
- 54 电荷扩散：带电色团排斥并向外扩散
- 55 相位闪移：能量带在相位差中快速错位
- 56 环形放电：多层电晕环连续扩张与消散
- 57 双极撕裂：两组反向场将色彩拉伸撕开
- 58 磁暴呼吸：大范围磁场缓慢收缩和膨胀
- 59 能量虹吸：一侧能量持续吸入另一侧核心
- 60 雷暴织网：细密电弧连接成动态网络

## 61–72｜天体引力

- 61 双星绕行：两个发光核心围绕共同质心旋转
- 62 引力深井：颜色沿弯曲空间向中心沉降
- 63 日冕喷发：环状火焰从恒星边缘向外抛射
- 64 星云融合：两团星云缓慢碰撞、交缠和混合
- 65 黑洞吸积：彩色物质沿吸积盘旋入暗核
- 66 行星潮汐：大尺度色团被引力拉成长带
- 67 彗尾漂移：高速核心拖出分层弯曲长尾
- 68 超新星扩散：中心爆发后形成多层扩散波
- 69 星团呼吸：多个星核同步明暗和聚散
- 70 暗质牵引：不可见力场让周围纹理产生偏折
- 71 引力透镜：背景色带绕核心形成弧形镜像
- 72 宇宙网脉：发光节点由长距离丝状结构连接

## 着色器架构

新增十八个结构场，每组六个：

- 晶体 `27–32`：晶核、枝晶、矿脉、棱面、碰撞、裂隙
- 电磁 `33–38`：双极、电弧、场线、脉冲、喷流、电荷
- 天体 `39–44`：轨道、引力井、日冕、星云、吸积、宇宙网

每个结构场输出四层材质遮罩。每组十二个研究通过不同结构场、速度和 `studyParams` 形成独立的节奏、方向、密度与事件过程；同一结构场最多服务两个语义相关但参数明显不同的效果。

新增三类统一的着色后处理：

- 晶体强调硬边、棱面、裂隙高光和局部虹彩
- 电磁强调细线亮度、场线对撞、冲击波和高能核心
- 天体强调旋转轨迹、空间弯曲、吸积层和远距离丝状连接

整体仍使用明亮、半透明、柔和的 SPECTRA 配色，不切换为黑色太空背景。

## 页面与交互

- 左栏分页从三个纵向按钮扩展为六个按钮。
- 标题与说明统一更新为七十二种动态、六页和全部七十二套配色。
- 随机按钮一次更新全部七十二项，但当前页面仍只挂载十二张画布。
- 暂停、播放、重置和分页行为保持不变。
- 重置回到 `01–12` 并恢复所有七十二项的默认参数。
- 左栏保持 sticky 和内部滚动，六个分页按钮不会撑破低高度视口。

## 性能约束

- 当前页始终只有十二个 2D canvas。
- 当前页始终只使用一个 WebGL2 context 和一个 atlas source canvas。
- atlas 仍为两列六行，不因目录扩展为七十二项而增大。
- 不增加第三方依赖，不引入逐卡 WebGL context 或真正的多步流体求解。

## 验收标准

- 目录精确包含七十二个连续、唯一的研究编号。
- 六页分别精确返回十二项，旧 01–36 的名称与 shader 映射保持不变。
- 新 37–72 的名称、章节、kernel、速度和参数均可确定性生成。
- shader 暴露 kernel `27–44` 的十八个结构场并可在浏览器编译。
- 每页浏览器中显示十二张卡片；37、49、61 和 72 的标签准确。
- 随机、暂停、播放、重置以及六页切换正常。
- 桌面和窄屏均无横向溢出，控制栏可访问全部六组。
- lint、生产构建和全部自动测试通过。
