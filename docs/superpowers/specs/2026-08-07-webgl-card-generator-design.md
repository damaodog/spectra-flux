# WebGL 动态卡片生成器设计说明

## 目标

构建一个单页在线动态卡片生成器。用户可以编辑卡片内容和视觉参数，实时预览 WebGL 动态效果，并复制一份无需外部依赖、可直接嵌入其他网页的自包含 HTML 片段。

首版聚焦一张卡片、一套生成逻辑和一个导出流程，不包含账号、云存储、模板社区、作品历史、分享链接或 GIF/视频导出。

## 视觉与布局

- 页面采用冷白背景、黑色极简排版、细描边和柔和阴影，延续参考图的克制科技感。
- 主体是一张超大圆角白色卡片。
- 左侧约 35% 为文字区域，右侧约 65% 为 WebGL 动态区域。
- 动态区随机融合粒子、波纹、雾、流体纹路和柔和渐变，每个预设组合 2–3 种效果，避免画面过载。
- 工作台采用“单卡专注画布”布局：大预览居中，常用操作紧贴预览下方，高级设置折叠收纳。
- 窄屏改为上下结构，文字在上、动态画布在下。

## 用户操作

页面载入后立即展示一张正在播放的默认卡片。用户可进行以下操作：

- 编辑标题、正文和辅助文字。
- 点击“随机生成”创建新的视觉组合。
- 播放或暂停动画。
- 修改配色、效果类型、尺寸、圆角、速度、强度和随机种子。
- 重置为默认配置。
- 点击“复制 HTML”将当前卡片作为自包含代码复制到剪贴板。

常用操作直接展示；文字、视觉和尺寸等详细参数放在“高级设置”中。所有设置变更即时更新预览。

## 技术结构

### CardPreview

负责卡片容器、左侧文字、右侧动态画布和响应式布局。它只消费当前卡片配置，不负责生成随机参数或导出代码。

### WebGLRenderer

优先使用 WebGL2 全屏四边形与 GLSL 片元着色器绘制动态区域。输入包括时间、画布尺寸、颜色、速度、强度、效果权重和随机种子。着色器以程序化噪声、距离场和周期函数组合粒子、波纹、雾与纹路，无需图片或远程资源。WebGL2 不可用时直接使用静态渐变降级，不维护第二套 WebGL1 着色器。

### ControlPanel

负责表单、播放状态和操作按钮。常用操作保持可见，高级参数默认折叠。每次修改产生一份完整配置并交给预览与导出模块。

### PresetEngine

从一个整数随机种子确定配色、效果组合及参数范围。同一种子和相同参数必须生成一致结果。随机生成会创建新种子，并保证新结果与上一结果存在可见差异。

### ExportBuilder

把当前文字、样式、参数、着色器和最小运行时代码序列化为单个 HTML 片段。片段由一个作用域根元素、内联样式和内联脚本组成，不声明完整文档结构，也不污染宿主页的全局样式。导出内容不加载第三方脚本、字体、图片或网络资源；粘贴进任意支持脚本的普通 HTML 页面后即可运行。

## 数据流

1. 页面以默认配置初始化预览。
2. 用户修改设置，控制面板生成新的完整配置。
3. 卡片预览更新文字与布局；WebGL 渲染器更新 uniform 参数。
4. 随机生成时，预设引擎根据新种子计算一组配置并覆盖当前视觉参数。
5. 复制 HTML 时，导出模块读取当前完整配置并生成自包含代码。

所有状态仅存在当前页面会话中。刷新页面后恢复默认状态，不建立持久化层。

## 兼容性与失败处理

- WebGL 初始化失败时，预览和导出内容退化为静态柔和渐变，并向用户显示简短提示。
- 剪贴板 API 不可用或被拒绝时，显示可手动选择和复制的代码框。
- WebGL 上下文丢失时暂停动画；上下文恢复后重新初始化资源并继续渲染。
- 页面遵守系统“减少动态效果”设置：默认暂停或显著降低动画速度，用户仍可手动播放。
- 输入文字在生成 HTML 时进行安全转义，确保特殊字符不会破坏导出结构。
- 卡片宽度允许 480–1600 像素，高度允许 220–900 像素，导出后仍以 `max-width: 100%` 适配宿主容器。圆角允许 24–96 像素，速度允许 0–2，强度允许 0–1。超出范围的输入自动限制到最近边界值。

## 性能约束

- 只创建一个 WebGL 上下文。
- 画布按设备像素比缩放，但设置合理上限，避免高分辨率屏幕造成过度渲染。
- 页面不可见、动画暂停或系统要求减少动态时停止渲染循环。
- 着色器保持单次全屏绘制，不使用多通道离屏渲染或大型纹理。

## 验收标准

- 页面首次打开即可看到一张布局正确、正在流动的动态卡片。
- 卡片桌面端保持约 35/65 的文字与动态比例；手机端自动切换为上下结构。
- 文字、颜色、速度、强度、圆角和尺寸调整即时生效。
- 相同种子与参数产生一致效果；随机生成产生明显不同结果。
- 播放、暂停和重置行为正确。
- 复制出的 HTML 在独立空白页面中呈现与预览一致的文字、布局和动画。
- 导出代码不发起第三方网络请求。
- WebGL 不可用、剪贴板权限失败、特殊字符和极端尺寸均有可用的降级行为。
- 键盘可操作所有表单和按钮，控件具有明确标签和焦点状态。

## 实施边界

首版为单路由、单卡片生成器。实现将优先使用平台原生 WebGL、Canvas、Clipboard 和表单能力，避免引入额外运行时依赖。后续若需要模板库、历史记录、分享链接或媒体导出，应作为独立增量设计。
