# 六款彩雾卡片对比器设计

## 目标

把当前单张 WebGL 卡片改成六款彩雾候选同时展示的本地对比器。用户可以一键让六张卡片分别随机，并按固定编号选择最接近参考图的烟雾结构。

## 卡片规格

- 默认导出尺寸为 800 × 300 px。
- 左侧文字区固定占 35%，即默认 280 px。
- 右侧彩雾区固定占 65%，即默认 520 px。
- 页面预览可以响应式缩小，但始终保持 800:300 的宽高比和 35:65 的内容比例。
- 白底、大圆角、左侧文字结构沿用当前版本。

## 六种固定结构

1. **柔雾扩散**：宽大、柔软、低频的色雾，从中部向右铺开。
2. **彩墨叠层**：不同颜色的独立半透明雾层前后叠加，重叠区域明显增色，综合色最浓烈。
3. **横向薄纱**：多层拉长雾带以不同速度横向流动。
4. **墨滴晕染**：局部色团向外扩散，边缘呈不规则渗透形态。
5. **斜向漂移**：前后雾层沿不同斜线移动，产生交叉透视。
6. **深景云雾**：大尺度背景雾叠加小尺度近景浓雾，纵深最明显。

六种结构均属于烟雾和彩雾家族，不混入粒子、波纹、射线或细密纹理。

## 彩色透明叠加

- 四层雾分别计算透明度和颜色，不先平均成单一颜色。
- 两种主色交替分配给前后雾层，并按图层顺序进行 Alpha 合成。
- 重叠区域提高颜色浓度，采用偏彩墨的强叠色，不做发光滤色。
- 左侧过渡保持乳白柔和，右边缘始终有颜色覆盖。
- 每层使用不同尺寸、模糊程度和运动速度，形成可辨认的前后关系。

## 页面与交互

- 六张卡片采用 2 × 3 响应式网格，同时可见并标注 `01` 至 `06`。
- 页面保留一个全局“一键全部随机”按钮。
- 随机时六张分别获得不同的种子、配色、速度和浓度；固定结构编号不变。
- 暂停、播放和重置同时作用于六张卡片。
- 文字内容和卡片尺寸为六张共享配置，随机操作不改变它们。
- 每张卡片保留独立复制 HTML 的入口，导出该编号当前的 800 × 300 卡片。

## 实现边界

- 复用当前 WebGL2 渲染组件、颜色预设和 HTML 导出逻辑。
- 使用一个片元着色器和一个 `variant` 整数 uniform 切换六种结构。
- 不新增第三方依赖，不新增服务端状态，不发布到 Sites。
- 本地入口保持 `http://localhost:3000/`。

## 验收标准

- 初次加载同时看到六张编号卡片。
- 每张预览与导出均保持 35% 文字区和 65% 彩雾区。
- 默认导出尺寸为 800 × 300 px。
- 第二款以及其他发生交叠的样式能清楚看到不同颜色雾层、综合色和前后透明关系。
- 连续点击一键随机后，六张视觉参数互不相同，但编号对应的结构不变。
- 六张动画可同时暂停和恢复，页面无 WebGL 编译错误或控制台错误。
- 核心测试、服务端渲染测试和生产构建全部通过。
