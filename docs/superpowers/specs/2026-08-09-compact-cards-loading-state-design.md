# SPECTRA FLUX 紧凑卡片与首页加载状态设计

## 目标

根据首页实际截图减少策展卡片的纵向占高，使首页卡片布局与效果库一致，把卡片圆角统一为 10px，并消除共享作品尚未返回时错误显示“尚未添加动态作品”的闪烁。

## 视觉设计

- 首页、效果库、随机实验室和独立嵌入页中的动态卡片统一使用 10px 圆角。
- 复制出的 iframe 同样使用 10px 圆角，保证调用结果与站内预览一致。
- 首页与效果库共用现有两列网格、`30px × 48px` 间距和响应式单列规则，不增加首页专用网格间距。
- 首页策展卡片的“查看配方”和操作按钮共享同一行，使其与效果库的单操作行结构一致，不再额外占一行。
- 操作按钮继续保留 44px 点击高度，避免为了紧凑牺牲可点击性。

## 首页加载状态

- `useCuration()` 尚未完成第一次共享状态读取时，首页作品区显示“正在加载共享作品…”骨架占位。
- 加载期间不得显示“尚未添加动态作品”，避免用户误以为内容被清空。
- 第一次读取结束后：有作品则显示卡片；确认为空才显示现有空状态入口。
- 加载失败时沿用现有警告信息，并结束加载状态，不无限等待。
- 骨架遵循 `prefers-reduced-motion`，减少动态设置下不播放闪烁动画。

## 实现边界

- 只调整现有 CSS、卡片半径常量/输出和首页条件渲染。
- 不改变 WebGL 动态算法、配方结构、Cloudflare KV 数据或管理权限。
- 不新增依赖或新的状态管理层。

## 验证

- 先增加失败测试，锁定 10px 圆角、首页与效果库的共享网格、同排操作区和加载优先级。
- 运行完整测试、构建和代码检查。
- 浏览器验证首页首次加载不闪空状态、卡片间距变紧凑、四类页面圆角一致。
- 部署后在 `https://spectra.8538690.xyz/` 再次验证正式站。
