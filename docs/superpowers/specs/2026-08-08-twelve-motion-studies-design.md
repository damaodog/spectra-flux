# 十二种墨流卡片设计

## 目标

把现有六张动态卡片扩展为十二张，在保持页面流畅的前提下新增六种能被直接感知的运动：撞击、扩散、融合、呼吸、快速与慢速。序号和名称移动到卡片外部上方，卡片内部仅保留 `SPECTRA` 与 `COLOR AS A LIVING SYSTEM.`。

## 页面结构

- 桌面端保持两列，十二张卡片组成六行；900 px 以下改为单列。
- 每个 `.card-study` 包含一行外部 `.study-meta` 和一张 `.preview-card`。
- 外部标签格式为 `01 · 柔雾扩散`，位于卡片上方并与卡片左边缘对齐。
- 卡片继续保持 400 × 100 px、25% 文字区和 75% 动态区。
- 页面标题、状态文字与页脚从“六张/六款”同步更新为“十二张/十二款”。

## 十二种效果

现有六种保留：

1. 柔雾扩散
2. 彩墨叠层
3. 横向薄纱
4. 墨滴晕染
5. 斜向漂移
6. 深景云雾

新增六种具有固定运动身份：

7. **双流撞击**：两股色流从相反方向向中心挤压，碰撞区出现高对比翻卷和交叠。
8. **墨云扩散**：局部墨团向外变宽、边缘变软，形成墨滴入水式扩散。
9. **色域融合**：两组色场交叉穿透，重叠区强化中间色与连续融合边界。
10. **潮汐呼吸**：云团尺度和密度使用连续正弦周期同步膨胀与收缩，不出现跳回原形。
11. **急速奔流**：定向拉伸的细长纹理高速穿过卡片，保持明显方向感。
12. **慢雾沉降**：大尺度低频雾层以最低速度缓慢漂移，形成厚重沉降感。

随机操作只更新十二张卡片的配色和种子；每张的 variant、名称和运动身份保持不变。新增六种使用受控速度，其中急速奔流最快、慢雾沉降最慢，避免随机速度破坏语义。

## WebGL 架构与性能

- 继续使用一个离屏 WebGL2 canvas、一个 shader program 和一条 `requestAnimationFrame` 循环。
- 图集保持两列并扩展为六行；每帧绘制十二个 viewport，再复制到十二个可见 2D canvas。
- 十二卡模式下设备像素比上限设为 1.5。400 × 100 px 卡片对应的图集约为 1200 × 900 px，总像素量接近当前六卡 2× DPR 图集。
- 不创建第二个 WebGL 上下文、不添加依赖、不增加独立动画循环。
- WebGL 不可用时继续显示每张卡片已有的 CSS 渐变背景；错误只写入控制台。
- 暂停时保留当前已复制画面，恢复后沿用原时间轴继续运动。

## 数据与着色器

- `SMOKE_VARIANT_COUNT` 从 6 改为 12，`createGallery()` 返回 variant `0–11`。
- `variantNames` 扩展为十二个固定名称。
- 现有 variant `0–5` 维持当前视觉逻辑；新增 variant `6–11` 在同一片元着色器内使用各自的空间变形、中心运动、密度和混色规则。
- 新效果复用当前噪声、fbm、涡旋和颜色混合函数，不引入新的渲染管线。

## 验证

- 自动测试确认十二个唯一 variant、十二张卡片、十二个 canvas 和十二个外部标签。
- 自动测试确认卡片内部不存在 `.card-meta`，新增名称和 `01–12` 均出现在 `.study-meta`。
- 自动测试确认图集为两列六行、十二卡 DPR 上限为 1.5，并仍只有一次 `getContext("webgl2")`。
- shader 测试确认 variant `6–11` 分别包含撞击、扩散、融合、呼吸、快速和慢速所需的独立控制分支。
- 浏览器检查外部标签不覆盖卡片，桌面两列/窄屏单列正确，十二张画面互不相同且持续运动。
- 浏览器检查随机、暂停、播放、重置、整卡悬浮和控制台错误状态。
