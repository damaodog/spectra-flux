# 柔和彩色烟雾视觉设计

## 目标

将动态卡片右侧的 WebGL 视觉收窄为参考图风格的柔和彩色烟雾。用户点击“随机生成”时只改变视觉，不改变左侧文字。

## 视觉规则

- 画面由 3–5 团大尺度彩色雾团组成。
- 雾团边缘柔软、低对比、半透明，彼此缓慢融合和分离。
- 白色从动态区左侧自然过渡到彩色烟雾，保持参考图的轻盈感。
- 不出现粒子、波纹、放射线、细密纹路、硬边或高对比黑烟。
- 动画速度克制，但雾团位移必须肉眼可见。

## 随机范围

“随机生成”只更新：

- 两个主色；
- 雾团位置、尺寸和移动方向；
- 动画速度与烟雾浓度；
- 随机种子。

标题、正文、辅助文字、卡片尺寸和圆角保持不变。

## 实现方式

- 保留现有单个 WebGL2 上下文和全屏四边形。
- 使用低频多层噪声与 domain warp 生成烟雾密度场。
- 使用 3–5 个软边距离场控制彩色雾团，随时间缓慢漂移。
- 预览与复制出的自包含 HTML 继续共用同一份 GLSL，确保效果一致。
- WebGL2 不可用时继续显示静态柔和渐变。

## 验收标准

- 默认卡片只显示柔和彩色烟雾，不再出现粒子、波纹和纹路。
- 播放时烟雾在一秒内产生可辨识的位置或形状变化。
- 暂停后画面保持静止，恢复播放后继续流动。
- 连续随机生成得到明显不同的配色和雾团构图。
- 随机生成前后左侧三段文字完全不变。
- 核心测试和页面渲染测试保持通过。

## 范围外

本轮不精简工作台、不新增烟雾类型选择、不加入模板库，也不发布或更新 Sites；只维护本地预览。
