# 扩散液态色场视觉设计

## 目标

将动态卡片右侧的 WebGL 视觉收窄为参考图风格的扩散液态色场。它不是由独立烟雾团组成，而是由超大柔性色块横向铺开、挤压和融合。用户点击“随机生成”时只改变视觉，不改变左侧文字。

## 视觉规则

- 画面由 2–3 个超大尺度彩色色块组成，色块超出画布边界，使右侧始终被颜色填满。
- 色块边界柔软、低对比、被强力模糊，像液体或凝胶相互挤压和融合。
- 白色从动态区左侧自然过渡到颜色，中右部颜色更饱和，保持参考图的轻盈感。
- 不出现独立圆形雾团、中心空洞、白色光斑、烟丝、粒子、波纹、放射线、细密纹路或硬边。
- 动画以缓慢的横向推移、缩放和边界形变为主，不模拟烟雾向上飘散。

## 随机范围

“随机生成”只更新：

- 两至三个主色；
- 大色块边界、水平位置、尺度和流动方向；
- 动画速度与颜色浓度；
- 随机种子。

标题、正文、辅助文字、卡片尺寸和圆角保持不变。

## 实现方式

- 保留现有单个 WebGL2 上下文和全屏四边形。
- 使用低频多层噪声与 domain warp 生成缓慢变化的色块边界。
- 使用 2–3 个超出画布范围的软边距离场，使色彩完整覆盖右边缘并避免孤立圆形轮廓。
- 以横向移动和尺度呼吸驱动动画，保持液态扩散感。
- 预览与复制出的自包含 HTML 继续共用同一份 GLSL，确保效果一致。
- WebGL2 不可用时继续显示静态柔和渐变。

## 验收标准

- 默认卡片只显示全幅扩散的液态色场，不再出现独立烟雾团、粒子、波纹和纹路。
- 动态区右边缘始终由颜色覆盖，不出现明显白色空洞。
- 播放时色块在一秒内产生可辨识的横向位置或边界变化。
- 暂停后画面保持静止，恢复播放后继续流动。
- 连续随机生成得到明显不同的配色和雾团构图。
- 随机生成前后左侧三段文字完全不变。
- 核心测试和页面渲染测试保持通过。

## 范围外

本轮不精简工作台、不新增烟雾类型选择、不加入模板库，也不发布或更新 Sites；只维护本地预览。
