# 单画布彩雾样式预览器设计

## 目标

把六张同时运行的彩雾画廊改成单张样式预览器，优先获得流畅的烟雾效果。六种结构继续保留，但任何时刻只挂载一个 WebGL canvas。

## 卡片规格

- 页面预览固定为 400 × 100 px，比例为 4:1。
- 左侧文字区占 35%，即 140 px。
- 右侧彩雾区占 65%，即 260 px。
- 卡片保持白底、大圆角、左侧文字和右侧彩雾结构。
- 本阶段不考虑导出尺寸、自包含 HTML 或其他地方复用。

## 样式切换

- 保留 `01` 至 `06` 六个固定烟雾结构。
- 页面只显示当前选中的一张卡片。
- 卡片下方显示六个编号按钮；点击后切换当前样式。
- 切换时 React 卸载旧的 WebGL 预览并挂载新预览，确保页面始终只有一个 canvas 和一个动画循环。
- 六个样式配置仍保存在内存中，切换编号不会重新随机或丢失该样式当前参数。

## 随机与控制

- “一键全部随机”继续为六种结构分别生成不同的种子、配色、速度和浓度。
- 随机完成后仍只渲染当前选中的样式，用户通过编号逐个查看。
- 暂停、播放和重置只作用于当前单画布和六个内存配置。
- 暂时移除复制 HTML、尺寸设置、文字设置和导出相关界面。

## 性能边界

- DOM 中必须只有一个 `.preview-card` 和一个 WebGL canvas。
- 单个彩雾区域的 CSS 尺寸为 260 × 100 px。
- 允许设备像素比最高为 2；即最大后台画布约 520 × 200，远低于六画布版本。
- 不引入额外的可见性监听、共享渲染器或离屏画布；单画布已经消除主要瓶颈。

## 验收标准

- 初次加载只显示一张 400 × 100 卡片和一个 canvas。
- 卡片保持 4:1，文字和彩雾列保持 35:65。
- `01–06` 均可切换，当前编号有清晰选中状态。
- 点击一键全部随机后，六个内存种子全部改变且互不重复，当前页面仍只有一个 canvas。
- 动画可暂停和恢复，切换样式后没有遗留动画循环或 WebGL 错误。
- 页面不再出现复制 HTML、导出或尺寸编辑控件。
- 核心测试、服务端渲染测试和生产构建通过。
