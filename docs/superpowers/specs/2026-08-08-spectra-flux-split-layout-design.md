# SPECTRA FLUX 左右布局设计

## 目标

将现有三十六款 WebGL 动态卡片网站改为更适合持续浏览的左右布局，并将网站正式命名为 **SPECTRA FLUX｜光谱流域**。本次只调整页面骨架与品牌文案，保留当前视觉语言以及全部动画行为。

## 品牌

- 英文站名：`SPECTRA FLUX`
- 中文释义：`光谱流域`
- 浏览器标题：`SPECTRA FLUX — Generative Motion Atlas`
- 品牌气质：编辑感、实验性、克制、精密
- 保留卡片内部的 `SPECTRA` 与 `COLOR AS A LIVING SYSTEM.` 文案

## 桌面布局

页面主体使用两列网格：

- 左侧为约 `320px` 的信息栏，滚动时使用 `position: sticky` 保持可见。
- 右侧为现有两列卡片画廊，每页继续展示十二张 `400 × 100` 卡片。
- 左侧依次放置品牌、状态、主标题、介绍、随机/暂停/重置操作、三类分页和当前状态提示。
- 右侧仅呈现序号、效果名称与动态卡片，让浏览焦点集中在样式比较。
- 页面底部的技术信息并入左侧信息栏，不再横跨整页。

## 视觉语言

完整延续当前页面：

- 米白背景与黑色正文
- 黑白像素纹理品牌标识
- 超大紧凑中文标题
- 细灰分隔线、胶囊按钮、大圆角卡片和轻柔阴影
- 当前卡片文字比例、75% 动态区域和悬停上浮反馈

不引入新的色彩系统、字体或组件库。

## 响应式行为

- 宽屏：左侧固定信息栏，右侧双列卡片。
- 中等宽度：左右结构转为上下结构，控制区不再 sticky，卡片仍尽量保持双列。
- 手机：单列卡片，操作按钮允许自然换行，卡片比例保持 `4:1`。
- 遵守 `prefers-reduced-motion`，不增加额外动画。

## 保持不变

- 三十六种 WebGL 动画与三类目录
- 单 WebGL atlas 的性能架构
- 随机全部、暂停/播放和重置逻辑
- 每页十二张、三页分页逻辑
- 动画速度、配色、噪声参数和着色器字段

## 验收标准

- 页面可见品牌为 `SPECTRA FLUX`，文档标题同步更新。
- 桌面宽度下主体呈左右布局，左侧宽度约 `320px` 且滚动时保持可见。
- 右侧仍为两列、每页十二张、每张 `400 × 100`。
- 小屏会自然退化为上下布局和单列卡片。
- 随机、暂停、重置与分页均继续工作。
- 生产构建、lint 和现有自动测试通过，并新增品牌与左右布局的回归断言。
