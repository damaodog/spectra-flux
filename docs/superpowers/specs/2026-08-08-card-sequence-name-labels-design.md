# 六卡序号与名称标签设计

## 目标

在现有六张 `SPECTRA` 卡片中显示可见的序号和样式名称，同时保持 400 × 100 px、25/75 分栏、共享 WebGL 图集和现有动画性能不变。

## 视觉方案

- 在每张卡片左侧白色文字区顶部增加一行小型等宽标签。
- 标签格式为 `01 · 柔雾扩散`，依次显示 `01–06`。
- 六个名称沿用代码中已有的：柔雾扩散、彩墨叠层、横向薄纱、墨滴晕染、斜向漂移、深景云雾。
- 标签使用低对比灰色、紧凑字号，不遮挡下方的 `SPECTRA` 与 `COLOR AS A LIVING SYSTEM.`。

## 实现范围

- 复用现有 `variantNames`，不新增状态、依赖或数据结构。
- 在卡片文字区渲染一个 `card-meta` 元素，并用 CSS 绝对定位。
- 序号和名称仅作视觉补充；卡片现有的无障碍标签继续提供完整编号。

## 验证

- 服务端 HTML 中应出现六个 `card-meta` 标签，以及 `01–06` 和对应名称。
- 现有六卡数量、400 × 100 px、25/75 分栏和单 WebGL 图集测试继续通过。
- 浏览器中检查标签不重叠，动画、随机、悬浮和暂停不受影响。
