# SPECTRA FLUX

> 144 种 WebGL 单效果、可精细约束的随机混合实验室，以及由管理员维护的共享动态策展首页。

**在线预览：** [spectra.8538690.xyz](https://spectra.8538690.xyz)

![SPECTRA FLUX 页面预览](docs/images/spectra-flux-preview.png)

SPECTRA FLUX 是一座运行在浏览器里的生成式动态视觉工作室。统一的 400 × 100 白色圆角卡片承载烟雾、薄纱、流体、光学、晶体、电磁、引力、液态金属、生物形态、地质、声场、拓扑与相变等视觉系统。

## 三个页面

- `/` 策展首页：所有访客看到同一份精选作品；每页最多 12 张，每张都能复制 HTML 调用代码。
- `/library` 效果库：浏览全部 144 种单效果。进入管理模式后，可以把喜欢的版本加入首页，或从效果库删除。
- `/lab` 随机实验室：选择 1–6 个效果，并约束混合强度、速度范围、配色、互动、节奏、构图、密度和边缘质感。

## 随机混合

混合并不是在几个效果之间轮流过渡。实验室会把多个效果放进同一个 WebGL 着色器，通过融合、碰撞、交缠、吞噬、光叠与差异切割共同作用。每一层都有独立、连续且受上下限约束的随机变速，速度会忽快忽慢但不会倒退或越界。

“更多随机约束”提供五类创作方向：

- 互动方式：融合、撞击、交缠、吞噬、光叠或差异切割。
- 节奏方式：漫游、呼吸、忽快忽慢、脉冲撞击或持续涌流。
- 构图方式：横向、中心碰撞、两侧夹击、旋涡汇聚或交错穿插。
- 视觉密度：轻薄留白、标准或浓密饱满。
- 边缘质感：柔雾、软硬混合或锋利纹路。

## 管理模式与共享策展

首页点击“管理”，输入服务器设置的管理密码后，才会出现加入首页、删除和导出策展配置等按钮。登录状态保存在安全的浏览器会话 Cookie 中，最长 12 小时；密码不会写入浏览器存储。

共享首页与效果库删除记录保存在 Cloudflare KV。管理员的修改会成为所有访客看到的内容。旧版本浏览器里的本机策展不会自动覆盖服务器；登录后可在管理面板中点击“同步本机策展”，确认后去重合并。

## 在其他网页调用卡片

首页每张作品和随机实验室当前作品都有“复制 HTML”按钮。它会复制一个固定 400 × 100 的 `<iframe>`，直接粘贴到支持 HTML 的网站即可。配方完整写入 `/embed` 地址，不依赖策展首页是否继续保留该作品。

本地开发时复制的地址使用当前 `localhost`；线上复制固定使用 `https://spectra.8538690.xyz`。

## 性能结构

每页只渲染 12 张卡片。单效果页使用一块 2 × 6 WebGL atlas，混合首页也只使用一个 WebGL2 context；结果再复制到 12 个轻量 2D canvas。实验室和嵌入页面各自只渲染一张卡片。

## 本地运行

需要 Node.js 22 或更高版本：

```bash
npm install
copy .dev.vars.example .dev.vars
npm run dev
```

打开 [http://localhost:3000/](http://localhost:3000/)。首次运行前，请在 `.dev.vars` 中更换管理密码和至少 32 位的随机会话密钥；这个文件已被 Git 忽略。

完整检查：

```bash
npm run lint
npm test
```

## Cloudflare Worker 配置

生产环境需要一个 Cloudflare KV 命名空间，并绑定为 `CURATION_KV`。构建时将命名空间 ID 放入 `SPECTRA_CURATION_KV_ID`，再运行 `npm run build:cloudflare`。同时用 Wrangler 配置两个加密 Secret：

- `SPECTRA_ADMIN_PASSWORD`：管理模式密码。
- `SPECTRA_SESSION_SECRET`：至少 32 位的随机会话签名密钥。

项目的 Worker 名称为 `spectra-flux`，自定义域名为 `spectra.8538690.xyz`。
